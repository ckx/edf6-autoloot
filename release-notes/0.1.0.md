# 0.1.0 offline preview

Collects remaining weapon and armor crates on an offline mission clear, through
the game's pickup function. Health, drop rates and pickup limits are unchanged.
Online collection is disabled.

This is an experimental prerelease. Automated tests exercise the supported game's
code under Wine. Live missions and multiplayer compatibility have not been verified.
Supports the Steam January 2025 EDF.dll build; other builds are refused.

Extract the ZIP into a separate folder. On Windows run INSTALL.bat; on Linux run
`bash install.sh`. Both detect Steam libraries, or accept an explicit game folder.
EDFModLoader must already be installed. Existing loader files, settings and other
mods are preserved. Close EDF6 first and back up your saves before testing.
Remove old Lootmaster files using the saved installation manifest before installing.
The installer detects its readme, but cannot detect every modified installation.

Run UNINSTALL.bat or `bash install.sh --uninstall` to remove AutoLoot.
Updates and removal save the previous DLL in an AutoLoot-backup-* folder beside
EDF6.exe. With the game closed, copy that DLL back to Mods/Plugins to roll back.
